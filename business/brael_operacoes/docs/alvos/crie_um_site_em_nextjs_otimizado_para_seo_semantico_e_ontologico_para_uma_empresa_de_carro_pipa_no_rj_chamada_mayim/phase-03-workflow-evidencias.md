# PHASE_03 — Evidências resumidas do workflow e checklist anti-canibalização

## Aderência ao workflow (resumo)
1. Pilar definido: falta de água no RJ + continuidade operacional.
2. Clusters definidos: contingência, dimensionamento de volume, qualidade da água.
3. Intenção por tópico separada para evitar canibalização.
4. Interlinking aplicado: artigos -> serviços transacionais + artigos relacionados.
5. Schema aplicado: `Article` + `FAQPage` nos artigos.

## Checklist anti-canibalização
- [x] Cada artigo com `title` e `description` únicos.
- [x] Keywords principais diferentes por slug.
- [x] Conteúdo orientado por intenção (informacional) e ponte para conversão.
- [x] Links cruzados para serviços de intenção transacional.
